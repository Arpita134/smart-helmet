# smart-helmet
A Low Cost IoT Smart Helmet for Accident Detection & Rider SafetyThis repository contains the hardware architecture, embedded C code, and documentation for Jaddo-i-Helmet, co-developed by Team Micro Farad during an internal hackathon. The project tackles the theme of Smart Vehicles and Hardware-based road safety solutions.  Hackathon Project Details
Theme: Smart Vehicles (Hardware)  
Project Overview Smart Helmet (SafeRide) is a low-cost, retrofit smart helmet kit designed to integrate the rider and helmet into one cohesive safety system. Developed collaboratively by our team, the system automates emergency responses using a "Prevent → Detect → Respond" methodology, rather than relying on rider-initiated alerts. 
Key Features Crash Detection: Uses an accelerometer/gyroscope to detect impacts and sudden tilts. Our custom sensor fusion score prevents false alarms and allows a 15-second rider-cancel window.  
Automated SOS: Sends an automatic SMS alert with GPS location to emergency contacts within 30 seconds of a confirmed crash, securing the critical "Golden Hour".  Preventative Safety: Includes helmet authentication via IR sensors (aiming for >95% compliance via interlock), MQ-3 alcohol detection, and drowsiness alerts.  Retrofit Design: Built as a miniaturized PCB that sits in the EPS liner cavity without drilling the outer shell, ensuring the rider keeps their existing BIS (IS 4151) certified helmet.  🛠️ Technology Stack & ArchitectureOur team engineered the system to operate on a two-node control architecture (Helmet Unit and Vehicle Unit) programmed in Embedded C. Cost AnalysisWe ensured every module is commercially available and proven, requiring no custom silicon.  Prototype Total: ~ ₹2,300  Projected Unit Cost (at 1,000-unit volume): ~ ₹1,400  
Impact & Scalability Scalability: The retrofit form factor makes it ideal for fleet rollouts among delivery and ride-hailing operators, driving schools, and state road-safety programs.  Economic Value: Prevention and faster emergency response reduce treatment costs and lost earnings, combating the 3% GDP loss attributed to road crashes in India (MoRTH/World Bank).
